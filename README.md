# python-practice

Данный проект представляет собой процесс обучения автоматизации тестирования на языке программирования Python с использованием библиотеки pytest.

---
### Задача 1 (task01_run_metrics)

Сбор метрик по пройденным тестам: процент успешных тестов, "зелёная" ли сборка, сколько длится прогон.  
Реализована функция `pass_rate`, принимает количество успешных тестов и общее число тестов, возвращает процент выполнения тестов. Результатом функции мы получаем число типа `float`, округлённый до двух знаков.  

metrics.py - основная логика  
test_metrics.py - тесты  
main.py - интерактивный скрипт: input → print  

---
### Запуск тестов

Перейти в корень проекта  
Выполнить `pytest -v`

---
### Известные ограничения

Если передать pass_rate(0, 0), будет деление на ноль. Пока считаем, что total > 0
