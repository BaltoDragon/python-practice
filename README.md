# python-practice

Данный проект представляет собой процесс обучения автоматизации тестирования на языке программирования Python с использованием библиотеки pytest.

---
### Задача 1 (task01_run_metrics)

Сбор метрик по пройденным тестам: процент успешных тестов, "зелёная" ли сборка, сколько длится прогон.  
На ввод подаётся общее количество пройденых тестов, количество успешных тестов, сколько из них завалено, а также  время прогона в секундах.  
Функция `pass_rate`, принимает количество успешных тестов и общее число тестов, возвращает процент выполнения тестов. Результатом функции мы получаем число типа `float`, округлённый до двух знаков.  
Функция `is_build_green`, принимает количество `failed` тестов, количество `broken` тестов, возвращает логическое значение типа `bool` с результатом `True`, когда сборка зелёная (ни одного заваленого или сломанного), `False` в противном случае.  
Функция `format_duration`, принимает время в секундах, возвращает это же время в формате строки "N мин M сек".  

metrics.py - основная логика  
test_metrics.py - тесты  
main.py - интерактивный скрипт: input → print  

---
### Запуск тестов

Перейти в корень проекта  
Выполнить `pytest -v`

### Известные ограничения

Если передать pass_rate(0, 0), будет деление на ноль. Пока считаем, что total > 0  
Ни один ввод не "переваривает" строки и тип `float`. Вводить исключительно `int`.
