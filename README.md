# python-practice

Данный проект представляет собой процесс обучения автоматизации тестирования на языке программирования Python с
использованием библиотеки pytest.

---

### Задача 1 (task01_run_metrics)

Сбор метрик по пройденным тестам: процент успешных тестов, "зелёная" ли сборка, сколько длится прогон.  
На ввод подаётся общее количество пройденных тестов, количество успешных тестов, сколько из них завалено, а также время
прогона в секундах.  
Функция `pass_rate`, принимает количество успешных тестов и общее число тестов, возвращает процент выполнения тестов.
Результатом функции мы получаем число типа `float`, округлённый до двух знаков.  
Функция `is_build_green`, принимает количество `failed` тестов, количество `broken` тестов, возвращает логическое
значение типа `bool` с результатом `True`, когда сборка зелёная (ни одного заваленного или сломанного), `False` в
противном случае.  
Функция `format_duration`, принимает время в секундах, возвращает это же время в формате строки "N мин M сек".  
Функция `is_within_tolerance`, принимает реальное значение, ожидаемое и допуск. Если разница между реальным и эталонным
значениями в допуске, возвращает значение типа `bool` `True`, в противном случае `False`.

metrics.py - основная логика  
test_metrics.py - тесты  
main.py - интерактивный скрипт: input → print

### Известные ограничения

Программа работает только с целыми числами. Если ввести в любую форму ввода число типа `float`, программа завершится с
ошибкой `ValueError`.   
Функция `pass_rate` пока не принимает количество общих тестов = 0. В противном случае программа завершится с ошибкой
`ZeroDivisionError`.  
Функция `pass_rate` пока не принимает количество общих тестов < 0. В противном случае вернётся отрицательный процент.  
Ни один ввод не "переваривает" строки и тип `float`. Вводить исключительно `int`.
